# Manuscript figure scripts

This directory contains the scripts and TeX wrappers copied from the active
Neuron manuscript working copy on 2026-08-30. They document how the current
main and supplementary figures were generated or assembled.

Several scripts expect the full local manuscript tree and derived result tables
that are not bundled in this compact reviewer-code repository. In this public
copy they are provided primarily for auditability: reviewers can inspect the
plotting logic, typography/layout settings, file names, and provenance links
used in the submitted figures.

The standalone runnable code path in this repository is the synthetic benchmark
under `src/synthetic_workspace/`. The full macaque ECoG rerun is documented in
`src/ktmd_corrected_montage/` and requires external raw data.
