# Reviewer access instructions

## Code location

https://github.com/kanair-gif/gmw-neuron-review-code

## Instructions for access

The repository is public and can be accessed anonymously without a login, password, or any request for personal information. Reviewers may either open the repository in a browser, download `gmw-neuron-review-code-20260830.zip`, or clone the repository with:

```bash
git clone https://github.com/kanair-gif/gmw-neuron-review-code.git
```

Direct ZIP download:

```text
https://raw.githubusercontent.com/kanair-gif/gmw-neuron-review-code/main/gmw-neuron-review-code-20260830.zip
```

The ZIP contains the custom synthetic-network generators, boundary Hankel mediation calculations, corrected-montage macaque ECoG analysis code, manuscript figure-generation scripts, small configuration/result tables, and provenance notes underlying the manuscript.

The full macaque ECoG rerun requires third-party NeuroTycho raw archives or split archive parts. These large raw data are not redistributed in the code repository. The expected raw archive filenames, sizes, and SHA-256 checksums are documented in the package under `src/ktmd_corrected_montage/.../pipeline/expected_master_index.json` and summarized in `data/README.md`.
